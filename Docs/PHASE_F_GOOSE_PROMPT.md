# Goose Agent Prompt — Phase F: Renewals Module

> Phases A through E are complete. MCA King now has activity/tasks, lender offer isolation, funded deals + broker revenue + internal sales rep commissions, merchant-file submissions, search/saved views, and account settings/admin user management. Phase F adds renewal tracking so the broker shop can follow up with funded merchants for additional funding opportunities and request payoff letters from current lenders/funders when needed.

---

## Business Model Rules — Read Before Writing Anything

MCA King is a **broker-shop CRM**, not a lender-originated deal marketplace.

```txt
Admin = broker shop owner/operator
Sales Rep = internal broker-shop rep
Merchant = funding applicant/customer
Lender/Funder = external funding company reviewer/approver
```

Hard business rules:

```txt
Lenders do not submit merchant deals into MCA King.
Lenders review merchant files that the broker shop submits/matches to them.
Renewals are broker-shop follow-up workflows after a merchant has funded.
No ISO payout model.
No referral partner model.
No outside broker commission model.
No lender-side manager payout model.
```

For Phase F specifically:

```txt
Renewal = broker shop opportunity to re-engage a previously funded merchant.
Payoff/consolidation workflow = broker shop tracks payoff information from current funders/lenders.
Lenders/funders should not see broker renewal queues, payoff strategy, or competing renewal opportunities.
Merchants may see safe renewal eligibility messaging/CTA only for their own account.
MCA King must not generate, create, or represent an official payoff letter on behalf of a lender/funder.
The broker shop only requests a payoff letter from the current lender/funder, tracks the request, and uploads/links the received lender/funder-provided document.
```

## Goal

Create a first-class **Renewals** workflow:

1. Track renewal eligibility for funded merchants.
2. Give admins and sales reps a renewal queue.
3. Allow broker users to record contact attempts, renewal status, estimated balances, payoff amounts, and notes.
4. Track payoff requests sent to current lenders/funders, and link the received payoff letter document when the lender/funder provides it.
5. Surface safe merchant-facing renewal eligibility messaging and CTA.
6. Keep lenders/funders out of broker renewal strategy and payoff workflow.

## Step 2 — Database Schema

Create two new tables:

```sql
create table if not exists public.renewals (
  id uuid primary key default gen_random_uuid(),
  merchant_id uuid not null references public.merchants(id) on delete cascade,
  funding_id uuid references public.fundings(id) on delete set null,
  eligibility_date date not null,
  status text not null default 'not_ready' check (
    status in (
      'not_ready',
      'eligible',
      'contacted',
      'application_started',
      'submitted',
      'renewed',
      'declined',
      'not_interested'
    )
  ),
  estimated_balance numeric,
  payoff_amount numeric,
  assigned_rep_id uuid references public.users(id) on delete set null,
  last_contacted_at timestamptz,
  next_follow_up_at timestamptz,
  notes text,
  created_by uuid references public.users(id) on delete set null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  unique (merchant_id, funding_id)
);

create table if not exists public.payoff_requests (
  id uuid primary key default gen_random_uuid(),
  merchant_id uuid not null references public.merchants(id) on delete cascade,
  funding_id uuid references public.fundings(id) on delete set null,
  renewal_id uuid references public.renewals(id) on delete set null,
  requested_from_lender_id uuid references public.lenders(id) on delete set null,
  requested_from_name text,
  payoff_amount numeric,
  requested_at timestamptz not null default now(),
  received_at timestamptz,
  expires_at timestamptz,
  file_document_id uuid references public.documents(id) on delete set null,
  status text not null default 'requested' check (
    status in ('requested', 'received', 'expired', 'used', 'cancelled')
  ),
  notes text,
  created_by uuid references public.users(id) on delete set null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
```

Indexes:

```sql
create index if not exists renewals_merchant_idx on public.renewals(merchant_id);
create index if not exists renewals_funding_idx on public.renewals(funding_id);
create index if not exists renewals_status_eligibility_idx on public.renewals(status, eligibility_date);
create index if not exists renewals_assigned_rep_idx on public.renewals(assigned_rep_id);
create index if not exists renewals_next_follow_up_idx on public.renewals(next_follow_up_at);

create index if not exists payoff_requests_merchant_idx on public.payoff_requests(merchant_id);
create index if not exists payoff_requests_funding_idx on public.payoff_requests(funding_id);
create index if not exists payoff_requests_renewal_idx on public.payoff_requests(renewal_id);
create index if not exists payoff_requests_requested_from_lender_idx on public.payoff_requests(requested_from_lender_id);
create index if not exists payoff_requests_status_idx on public.payoff_requests(status);
create index if not exists payoff_requests_expires_idx on public.payoff_requests(expires_at);
create index if not exists payoff_requests_document_idx on public.payoff_requests(file_document_id);
```

Security:

```sql
alter table public.renewals enable row level security;
alter table public.payoff_requests enable row level security;

create policy "block_public_renewals" on public.renewals for all using (false);
create policy "block_public_payoff_requests" on public.payoff_requests for all using (false);
```

Optional document type:

- Inspect current `documents.doc_type` constraints before changing anything.
- If the DB has a check constraint that supports adding a new value safely, add `payoff_letter` to document type support.
- If changing the constraint is risky, use existing `doc_type = 'other'` and link the received document via `payoff_requests.file_document_id`.
- Do **not** break existing document upload behavior.


```txt

```
