The Golden Rule of Phase I

We must first build the Communications Center + Compliant Campaign Foundation. The biggest risk is not sending the message—it is sending messages incorrectly. Phase I focuses on tracking preferences, managing suppressions, and building provider abstractions before enabling any bulk sends.

Email Routing & CAN-SPAM

This section details the necessary separation of email types to protect domain reputation and the specific legal requirements under CAN-SPAM that our application must enforce programmatically. You will find rules for routing logic and content compliance.

Email Classification

Critical path communications expected by the user.

  • ➤ Password resets & account creation
  • ➤ Merchant application updates
  • ➤ Document / stipulation requests
  • ➤ Funding / Deal status alerts

Promotional or bulk outreach requiring strict compliance.

  • ➤ Follow-up campaigns to cold leads
  • ➤ Merchant nurture drip campaigns
  • ➤ Renewal marketing & cross-selling
  • ➤ "We can help you get funding" blasts

CAN-SPAM Application Rules

✗

No Deceptive Headers

Subject lines and 'From' names must clearly identify the sender and intent.

📬

Physical Address

App templates must inject a valid physical mailing address in the footer.

✓

Clear Unsubscribe

Every campaign email must contain a generated, trackable unsubscribe link.

⏱

10-Day Honoring

System must instantly update suppression lists. Legal limit is 10 days.

📈 Provider Routing Strategy

Do NOT use Zoho Mail for app campaigns. It risks the business inbox. Use Resend via API.

// Pseudo-code for Provider Abstraction
function sendEmail(contactId, templateId, type) {
  if (type === 'MARKETING') {
    checkSuppressionList(contactId);
    injectUnsubscribeLink(templateId);
    applyRateLimits();
  }
  return ResendProvider.send(...);
}

SMS Marketing & TCPA Guidelines

This section covers the highly regulated landscape of automated SMS. SMS requires explicit, documentable opt-in. The application must handle carrier regulations (A2P 10DLC) and automated opt-outs (STOP) seamlessly before any text is dispatched.

⚠

No Blasting. No Cold SMS.

SMS is much stricter than email. Unsolicited text messages create massive legal exposure under TCPA and will result in immediate carrier filtering and account suspension.

Express Written Consent Requirements

When a lead submits a form, the UI must display clear disclaimer language. The backend must store the following audit trail:

  • ✓ Who opted in (Phone / ID)
  • ✓ Exact Timestamp of Opt-In
  • ✓ Source URL / Form ID
  • ✓ IP Address (if available)
  • ✓ Exact Consent Language Shown
Required UI Language

"By providing your phone number, you agree to receive calls and text messages from [Broker Name] about funding options. Message and data rates may apply. Message frequency varies. Reply STOP to opt out, HELP for help."
